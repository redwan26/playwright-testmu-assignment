# Playwright 101 Assignment

This project contains automated Playwright tests for the TestMu AI Selenium Playground.

## Scenarios Covered

1. Simple Form Demo
2. Drag and Drop Slider
3. Input Form Submit

## Browser/OS Combinations

- Chrome on macOS Sequoia
- MicrosoftEdge on Windows 10

## Run

Create a `.env` file with:

LT_USERNAME=your_username
LT_ACCESS_KEY=your_access_key

Then run:

node playwright-single.js
